  helm test {{ .Release.Name }} --namespace {{ .Release.Namespace }}

Open Plumb Studio, and let the Figma plugin find the bridge:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "plumb.fullname" . }} {{ .Values.bridge.port }}:{{ .Values.service.port }}

  then open http://127.0.0.1:{{ .Values.bridge.port }}/

  The Figma plugin scans 127.0.0.1:31337-31346, so the port-forward above is
  what lets it pair with an in-cluster bridge. Keep the local port at 31337
  unless you have also changed the plugin.
